# LabPilot — HPLC 异常排查助手

LabPilot 帮助研发人员在出现色谱异常时确定排查顺序：根据 Blank、Standard、Sample、保留时间和系统状态等实际观察，给出优先排查方向、判断依据和下一步实验建议。

**在线体验：** https://youli-laura.github.io/labpilot-hplc-assistant/

## HPLC 是什么？

HPLC（高效液相色谱）是一种用于分离和分析混合物成分的技术，应用于药品与生物制药、食品、环境、化工与材料、临床及其他分析研发场景。它先把样品中的不同成分分开，再结合分析方法、色谱柱和检测条件进行定性或定量；实际工作中可用于含量测定、杂质分析、纯度评价和手性纯度分析等任务。

一次分析通常会同时运行 Blank（空白溶液）、Standard（标准品）和 Sample（样品）。如果色谱图中突然出现未知峰、保留时间变化或其他异常，研发人员需要判断问题来自溶液、样品、进样系统、色谱柱还是仪器状态。

## 为什么需要 LabPilot？

没有统一的排查工具时，研发人员通常需要查阅分析方法、SOP、仪器资料和历史记录，再安排多轮单变量实验逐步缩小范围。经验丰富的研究人员往往能更快找到起点；当经验不足或现象复杂时，最难的不是列出所有可能原因，而是决定先查什么、每次只改变什么，以及如何根据新结果继续下一步。

LabPilot 把当次实验观察放进同一条判断链路，先给出建议的排查顺序，再说明每个方向引用了哪些观察、应先验证哪个变量，以及异常改善或仍然存在时分别如何继续。它减少的是无方向的反复试验，不是替研发人员直接下结论。

## 不只是给出一串可能原因

LabPilot 不只是回答“可能是什么原因”，而是把实验观察采集、输入冲突检查、排查顺序、决策依据、操作后分支和合规停止条件放进同一套流程。

用户得到的不是一次性答案，而是一条可以执行、复核和留存的排查路径。

## 产品定位

LabPilot 是面向 HPLC 异常排查的决策辅助工具。它帮助研发人员记录观察、安排验证顺序并回看判断依据。

产品给出的是下一步应该先查什么，而不是直接宣布已经找到根因。每项建议仍需通过实验复核，并遵循所在实验室批准的程序。

## 适合谁使用？

- **研发人员：** 出现色谱异常时，按一致的顺序确认现象并安排下一步实验。
- **实验室主管或复核人员：** 查看排查建议依据了哪些观察，判断验证顺序是否合理。
- **参与异常评估的 QA 人员：** 核对是否触发停止条件，以及建议是否保持在质量体系允许的范围内。

## 核心能力

### 1. 先确认影响判断的关键观察

按排查需要确认峰出现范围、保留时间、Blank 表现、样品关系和系统状态，减少因关键信息缺失而走错方向。

### 2. 先排什么，一目了然

结果最多给出三个排查方向，并明确标出优先顺序。用户可以先处理最需要验证的方向，不必在一长串可能原因中自行决定从哪里开始。

### 3. 每个建议都能看到依据

展开“决策依据”即可查看本次判断引用的实验观察，便于研发人员和复核人员检查排查方向是如何形成的。

### 4. 做完一步后，知道下一步怎么走

每项建议说明应先改变哪个变量。操作完成后，分别给出“异常改善或消失”与“异常仍然存在”两条后续路径，帮助用户继续缩小范围。

### 5. 遇到高风险状态先停止

如果系统适用性测试（SST）未通过，结果会显示高风险停止提示，要求先处理系统状态问题，而不是继续用于样品结果报告。

### 6. 排查记录可以导出

PDF 报告包含本次实验观察、排查方向、判断依据、建议操作和合规声明，可用于后续复核、沟通和记录。

## 如何使用

1. **选择异常：** 确认本次需要排查的色谱现象。
2. **填写异常详情：** 记录异常出现位置、保留时间、Blank 和样品表现。
3. **确认系统状态：** 补充流动相、色谱柱、保护柱和系统适用性等信息。
4. **查看排查结果：** 按优先级查看排查方向、决策依据、建议操作和后续判断路径。

## 一个简单示例

假设未知峰同时出现在 Blank、Standard 和 Sample 中，首针 Blank 即明显出现，连续 Blank 中峰面积相对稳定，并且近期重新配制过流动相。

LabPilot 会优先提示检查流动相、试剂和容器是否带入污染，并列出支持这一方向的观察。建议操作要求逐项排查，每次只改变一个变量。若更换后未知峰消失，则继续复核该变量；若未知峰仍然存在，则转向系统公共流路或进样路径。

该示例只用于说明产品的判断过程，不包含真实公司、样品、批号或保密实验数据。

## 专业边界与设计原则

- **判断依据可以复核。** 每个排查方向都能回看本次判断引用的具体观察。
- **每次只验证一个变量。** 建议操作避免同时改变多个条件，以便判断哪项变化影响了结果。
- **相同输入得到一致结果。** 确定性规则使判断可以复现、测试和检查。
- **停止条件先于排查建议。** SST 未通过等风险状态会优先触发合规护栏。
- **产品不替代 SOP、QA、偏差调查或质量结论。** 最终操作和判断仍应遵循实验室批准的程序和质量体系要求。
