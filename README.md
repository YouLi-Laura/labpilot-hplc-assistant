# LabPilot — HPLC 异常排查助手

LabPilot 不替分析人员判断根因，而是帮助他们把 HPLC 异常排查理清楚：先把关键信息问完整，再给出有优先顺序和判断依据的排查方向，并在存在合规风险时明确停止。

**在线体验：** https://youli-laura.github.io/labpilot-hplc-assistant/

> 当前版本基于明确、可检查的确定性规则运行，不调用大模型生成质量判断，也不替代 SOP、QA、偏差调查或质量结论。

## HPLC 是什么？

HPLC（高效液相色谱）是一种用于分离、识别和测定样品中不同成分的分析技术，广泛应用于药品研发、质量控制和检验检测。

当色谱图中出现未知峰、保留时间变化或其他异常时，分析人员需要判断问题可能来自样品、流动相、进样系统、色谱柱还是仪器状态，并通过逐项实验缩小范围。

## LabPilot 解决什么问题？

HPLC 异常排查通常不是缺少可查的知识，而是现场观察比较零散：异常出现在哪类进样中、是否固定保留时间、Blank 如何变化、系统适用性是否通过，这些信息需要被放在一起判断。

如果过早锁定某个原因，容易反复更换多个条件，最后很难确认究竟是哪一个变量影响了结果；如果关键观察没有记录完整，后续复核也很难还原当时的判断过程。

LabPilot 将这些观察放进一套固定的提问和判断流程，帮助用户明确：

- 目前最值得先排查什么；
- 哪些实验观察支持这一方向；
- 建议先改变哪个变量；
- 操作后如何判断，以及下一步转向哪里。

## 产品定位

LabPilot 是面向 HPLC 异常排查的决策辅助工具。它把实验室观察整理成有优先顺序、能够回看依据并带有合规提醒的排查路径。

它提供的是排查起点和验证顺序，而不是未经复核的根因结论。最终操作仍应遵循所在实验室批准的 SOP 和质量体系要求。

## 适合谁使用？

- **QC 分析人员：** 在出现色谱异常时，按固定顺序收集观察并安排下一步实验。
- **实验室主管或复核人员：** 快速了解排查建议来自哪些实验现象，检查判断是否有依据。
- **参与异常评估的 QA 人员：** 查看系统是否触发停止条件，以及产品是否越过质量结论边界。

## LabPilot 的核心优势

### 1. 先把该问的问题问完整

系统通过分步向导收集峰出现位置、保留时间、Blank 表现、样品范围和系统适用性等观察。用户不需要先知道专业规则如何编排，也能按一致的顺序完成信息收集。

### 2. 告诉你先查什么，也告诉你为什么

结果不会只给出一串可能原因。每个排查方向都有明确优先级，并可以展开查看本次判断引用了哪些关键观察。用户可以复核依据，而不是直接接受一个不可解释的答案。

### 3. 做完一步后，知道接下来怎么看

每项建议都说明应优先改变哪个变量，并给出两种后续路径：如果异常改善或消失，如何通过单变量复核继续确认；如果异常仍然存在，下一步应转向哪个范围排查。

### 4. 该停止时明确停止

如果系统适用性测试（SST）未通过，LabPilot 会显示高风险停止提示，要求先处理系统状态问题，而不是继续用于样品结果报告。这一限制直接进入判断流程，不只出现在最后的免责声明里。

### 5. 排查过程可以复核和留存

用户可以导出 PDF 报告，保留本次实验观察、排查方向、判断依据和合规声明，便于后续复核、沟通和记录。

## 如何使用

1. **选择异常：** 确认本次需要排查的色谱现象。
2. **填写异常详情：** 记录异常出现位置、保留时间、Blank 和样品表现等观察。
3. **确认系统状态：** 补充流动相、色谱柱、保护柱和系统适用性等信息。
4. **查看排查结果：** 获得有优先级的排查方向、决策依据、建议操作和操作后的判断路径。

## 一个简单示例

假设未知峰同时出现在 Blank、Standard 和 Sample 中，首针 Blank 即明显出现，连续 Blank 中峰面积相对稳定，并且近期重新配制过流动相。

LabPilot 会把“流动相、试剂或容器带入的污染”放在较高优先位置，并列出支持这一判断的具体观察。建议操作会要求逐项排查和单独更换，避免一次改变多个变量。若更换后未知峰消失，则继续通过单变量复核定位；若未知峰仍然存在，则转向系统公共流路或进样路径排查。

该示例仅用于说明产品如何组织排查过程，不包含真实公司、样品、批号或保密实验数据。

## 专业设计与合规边界

- **优先级不等于证据支持度。** 某个方向可能因为风险或排查顺序需要优先处理，但现有观察对它的支持程度仍可能是中等或较低。
- **判断依据可回看。** 每个方向引用的观察默认折叠，用户需要时可以展开核对。
- **结论保持克制。** 文案使用“优先排查”“提示可能”和“需要复核”，不把规则命中写成已确认根因。
- **相同输入得到一致结果。** 确定性规则便于复现、测试和检查，不会为相同观察随机生成不同结论。
- **停止条件优先于排查建议。** SST 未通过等风险状态会先触发合规护栏。

## 当前实现与验证

本次公开版本以“未知杂峰”作为已经实现和验证的场景，用于展示完整的观察采集、规则判断、结果解释和报告导出流程。产品结构预留了继续扩展其他 HPLC 异常场景的空间，但未实现模块不会被描述为现有能力。

当前版本包括：

- 分步观察采集与输入冲突检查；
- 最多三个有优先级的排查方向；
- 分级显示证据支持度；
- 可展开的决策依据；
- SST 高风险停止护栏；
- 操作后的两类判断路径；
- 包含输入摘要和合规声明的 PDF 报告；
- 桌面端与移动端响应式界面。

自动化测试覆盖规则优先级、证据支持度、输入冲突、SST 护栏、结果渲染、PDF 导出契约、响应式布局和公开发布安全边界。

## 技术实现

- 原生 HTML、CSS 与 ECMAScript Modules；
